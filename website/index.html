Build, test, and run

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
./build/octopus demo

With Visual Studio, use build/Release/octopus.exe. The sample model returns the verified output [1.5, 1.5, 8.0].

Clear capabilities, measurable progress

Octopus currently runs on the CPU. CUDA, quantization, KV caching, and pretrained text generation are not implemented. Benchmarks measure actual execution and make no unsupported speedup claims.
